# 如何在 Windows 上執行「外掛模擬器」

給沒有寫過程式的人看的圖文步驟。照著做就行，大概 10 分鐘。

---

## 步驟 1：安裝 Node.js（只需做一次）

這是讓遊戲能跑起來的引擎。

1. 打開瀏覽器，進入官網：**https://nodejs.org/**
2. 點頁面上那個寫著 **「LTS」** 的綠色大按鈕（LTS = 穩定版），會下載一個 `.msi` 安裝檔
3. 點開下載的檔案，一路按 **「Next」→「Next」→「Install」**（全部用預設值就好）
4. 跳出「使用者帳戶控制」問你要不要允許 → 按 **「是」**
5. 裝完按 **「Finish」**

> 怎麼確認裝好了？不用特別確認，下面步驟能跑就代表成功。

---

## 步驟 2：下載遊戲

1. 用瀏覽器打開你的專案頁面：
   **https://github.com/Ludology7882/project_opencore**
2. 找到綠色的 **「\<\> Code」** 按鈕，點它
3. 在跳出的小選單最下面，點 **「Download ZIP」**
4. 下載完後，到「下載」資料夾找到那個 zip 檔
5. **對它按右鍵 → 「解壓縮全部」→ 「解壓縮」**
6. 會得到一個資料夾（名字類似 `project_opencore-claude-...`），記住它在哪

---

## 步驟 3：在那個資料夾打開命令列

這是最關鍵、也最容易卡住的一步，照著做：

1. 用「檔案總管」打開步驟 2 解壓出來的資料夾
   （要進到**裡面有 `config.txt`、`package.json` 這些檔案**的那一層）
2. 點一下視窗**最上面的網址列**（顯示路徑那條），整條會反白
3. 直接打字輸入 **`cmd`** 三個字母，按 **Enter**
4. 會跳出一個黑色視窗（命令提示字元），而且它已經停在你的遊戲資料夾了 ✅

---

## 步驟 4：安裝零件（只需做一次）

在剛剛那個黑色視窗裡，輸入這行，按 Enter：

```
npm install
```

它會自動下載需要的工具，跑個幾十秒，出現一堆文字是正常的。看到游標可以再輸入時就完成了。

---

## 步驟 5：開始遊戲！

在同一個黑色視窗裡，輸入：

```
npm start
```

按 Enter，遊戲就會跑起來，畫面開始滾動掛機日誌，最後印出結算。🎉

想要**逐行慢慢滾動**（比較有掛機感），改用這行：

```
npm run play
```

---

## 步驟 6：修改 config，找出最有效率的玩法

這才是遊戲的核心樂趣：

1. 在遊戲資料夾裡找到 **`config.txt`**
2. **對它按右鍵 → 開啟方式 → 記事本**
3. 改裡面的參數（例如把 `map B` 改成 `map C`，或調整技能、休息設定）
4. 存檔（記事本：檔案 → 儲存）
5. 回到黑色視窗，再輸入一次 `npm start`，比較看看結算數字（經驗/回合、淨金錢/回合）有沒有變好

---

## 常見問題

**Q：黑色視窗出現一堆奇怪的色碼符號？**
A：改用這行關掉顏色：`npm start -- --no-color`

**Q：想跑久一點 / 換個隨機種子？**
A：`npm start -- --ticks 200`（跑 200 回合）、`npm start -- --seed 7`（換種子）

**Q：關掉視窗後想再玩？**
A：重複步驟 3（在資料夾網址列打 `cmd`）+ 步驟 5（`npm start`）即可，步驟 1、2、4 不用重做。

**Q：`npm` 不是內部或外部命令？**
A：代表 Node.js 沒裝好，或要把黑色視窗關掉重開一次。重做步驟 1。
